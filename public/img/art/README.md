# Editorial photography

Drop licensed press / editorial photography here, then add each file in the CMS
(`/admin` → Gallery) with a path like `/img/art/shoot-01.jpg`.

No verified editorial photography of D_MAK was publicly accessible during
research, so every gallery slot currently shows official release artwork
instead. Supply the shoot files (JPEG, 1600px+ on the long edge) and they will
appear on /gallery and in the homepage hero rotation.
